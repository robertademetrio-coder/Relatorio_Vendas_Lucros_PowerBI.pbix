#  Dashboard Financeiro e Análise de Vendas com Power BI

##  Descrição do Projeto
Este projeto consiste em um relatório gerencial interativo desenvolvido no Power BI Desktop com base na base de dados `financials`. O objetivo principal é fornecer visualizações claras para tomada de decisão, analisando vendas, custos, lucros e métricas de TOP N por país e produto.

---

##  Funcionalidades e Estrutura do Relatório
O relatório é composto por 4 páginas com navegação intuitiva:
1. **Home:** Tela inicial de apresentação com botão de navegação direta.
2. **Principal:** Visão geral de métricas de vendas, evolução temporal e distribuição por produto/país.
3. **Detalhes:** Detalhamento segmental e análises complementares.
4. **TOPN & Outliers:** Análise focada nos 3 principais produtos (Top 3) e tendências acumuladas.

---

##  Tecnologias e Recursos Utilizados
- **Power BI Desktop**
- **Filtros Nativos** (Top N)
- **Design & UX:** Tema escuro personalizado, fundos transparentes e botões de navegação interativos via ações de página.
